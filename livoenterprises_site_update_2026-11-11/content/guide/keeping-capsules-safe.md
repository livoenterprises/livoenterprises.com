## Keep a copy

[Open Capsules › Keep a copy](livo://vault/places). **This phone** is always one place. Add up to five **folders of your own** from the Files app: iCloud Drive, Dropbox, Google Drive, a drive plugged into the phone. Every capsule you seal is copied to each of them. A place that is not reachable right now (a drive unplugged, no network) is simply "pending"; the copy is written the next time Livo sees it. Removing a place deletes nothing. With [Curator](/guide/curator.html), your OneDrive's **Livo Vault** folder is a place as well, on by default when you are signed in.

Livo writes only its own capsule files into a place and never deletes anything there.

## Checking

Livo quick-checks each capsule's copies about once a week on its own, and while the app is closed it may check a few in the background. **Check** at the top of Capsules offers **Check All**. A capsule's own screen has Quick Check and Verify Every File, which reads each copy and proves it byte for byte.

You only hear about trouble: one quiet notification when a copy needs attention, never a message that everything is fine.

## Repair, Re-seal, Lost

If one copy is damaged or missing, the capsule's screen offers **Repair** from a copy that checked out, in either direction. Nothing is ever replaced except from a verified copy, and a damaged file is moved aside, not deleted. If no good copy is left but the Memory is still here, **Re-seal from the Memory** makes a fresh capsule. If the Memory is gone too, the capsule is **Lost**, and Livo says so plainly.

## Keepsakes

For a Memory that must never change, one you inherited, **Keep forever (a Keepsake)** on its screen, or when you receive it, marks it so that it is only ever repaired, never re-sealed or overwritten. With Curator, a Keepsake also gets a third copy in OneDrive › **Livo Keepsakes**, a folder Livo writes once and never deletes from.
