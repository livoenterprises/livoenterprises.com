## Places

[Open Vault › Places](livo://vault/places). **This phone** is always one place. **OneDrive › Livo Vault** is the second, on by default when you are signed in: every capsule you seal is copied there. You can add up to five **folders of your own** from the Files app — iCloud Drive, Dropbox, Google Drive, a drive plugged into the phone — and every capsule goes there too. A place that is not reachable right now (a drive unplugged, no network) is simply "pending"; the copy is written the next time Livo sees it. Removing a place deletes nothing.

Livo writes only its own capsule files into a place and never deletes anything there.

## Checking

Livo quick-checks each capsule's copies about once a week on its own, and while the app is closed it may check a few in the background. **Check** at the top of the Vault offers **Check All**, **Check the Ones Not Checked in a While**, and **Verify Every OneDrive Copy** (which downloads each one and proves it byte for byte). A capsule's own screen has Quick Check, Verify Every File and Verify the OneDrive Copy.

You only hear about trouble: one quiet notification when a copy needs attention, never a message that everything is fine.

## Repair, Re-seal, Lost

If one copy is damaged or missing, the capsule's screen offers **Repair** from a copy that checked out — the phone's copy from OneDrive or a place, or the other way round. Nothing is ever replaced except from a verified copy, and a damaged file is moved aside, not deleted. If no good copy is left but the Memory is still here, **Re-seal from the Memory** makes a fresh capsule. If the Memory is gone too, the capsule is **Lost**, and Livo says so plainly.

## Keepsakes

For a Memory that must never change — one you inherited — switch on **Keep forever (a Keepsake)** on its screen, or answer yes when you receive it. A Keepsake gets a third copy in OneDrive › **Livo Keepsakes**, a folder Livo writes once and never deletes from, overwrites or re-seals. A Keepsake is only ever repaired, never re-sealed.
